# 🌐 Deploy: Netlify (Frontend) + Render (Backend)

This guide shows you how to deploy CyberGuard Academy with:
- **Frontend** on Netlify (Free, fast CDN)
- **Backend** on Render (Free tier with database persistence)

---

## 🚀 Quick Deployment

### Step 1: Deploy Backend to Render

1. Go to https://render.com
2. Sign up with GitHub
3. Click **"New +"** → **"Blueprint"**
4. Select your repository: `gamified-learning-system-for-cybersecurity-awareness`
5. Click **"Apply"**

Render will deploy the backend automatically. Note the backend URL (e.g., `https://cyberguard-backend.onrender.com`)

---

### Step 2: Deploy Frontend to Netlify

#### Option A: Drag & Drop (Easiest)

1. Go to https://app.netlify.com
2. Sign up/login
3. Click **"Add new site"** → **"Deploy manually"**
4. Drag the `FRONTEND` folder from your project into the upload area
5. Wait for deployment
6. Note your Netlify URL (e.g., `https://your-site.netlify.app`)

#### Option B: Connect to GitHub

1. Go to https://app.netlify.com
2. Click **"Add new site"** → **"Import an existing project"**
3. Select your GitHub repository
4. Configure:
   - **Build command**: `echo "No build required"`
   - **Publish directory**: `FRONTEND`
5. Click **"Deploy site"**

---

### Step 3: Update API Configuration

After both are deployed, you need to update the frontend to point to your backend:

1. Edit `FRONTEND/api.js`:
   ```javascript
   constructor() {
       // Change this to your Render backend URL
       this.baseURL = 'https://cyberguard-backend.onrender.com/api';
       this.token = localStorage.getItem('authToken');
   }
   ```

2. Update `render.yaml`:
   ```yaml
   envVars:
     - key: FRONTEND_URL
       value: https://your-netlify-site.netlify.app
   ```

3. Commit and push changes:
   ```bash
   git add .
   git commit -m "Update API URLs for production"
   git push origin main
   ```

4. Render will automatically redeploy with the new configuration.

## 📋 Configuration Files

### `netlify.toml` (Frontend)
```toml
[build]
  publish = "FRONTEND"
  command = "echo 'No build required'"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

[[redirects]]
  from = "/api/*"
  to = "https://cyberguard-backend.onrender.com/api/:splat"
  status = 200
```

### `render.yaml` (Backend)
```yaml
services:
  - type: web
    name: cyberguard-backend
    runtime: node
    rootDir: BACKEND
    buildCommand: npm install
    startCommand: node server-sqlite.js
    envVars:
      - key: JWT_SECRET
        generateValue: true
      - key: PORT
        value: 10000
      - key: FRONTEND_URL
        value: https://your-netlify-site.netlify.app
    disk:
      name: database
      mountPath: /opt/render/project/src/BACKEND
      sizeGB: 1
```

## 🐛 Troubleshooting

### CORS Errors
Update `BACKEND/server-sqlite.js`:
```javascript
app.use(cors({
    origin: [
        'http://localhost:8000',
        'https://your-netlify-site.netlify.app'
    ],
    credentials: true
}));
```

### API Not Connecting
1. Check `FRONTEND/api.js` has correct backend URL
2. Verify backend is running on Render
3. Check browser console for errors

### Database Not Persisting
Make sure disk is configured in Render:
- Name: `database`
- Mount Path: `/opt/render/project/src/BACKEND`
- Size: 1 GB

## 💡 Tips

1. **Test locally first** - Run `start-app.bat` to verify everything works
2. **Use environment variables** - Don't hardcode URLs
3. **Monitor logs** - Check both Netlify and Render logs for errors
4. **Enable HTTPS** - Both platforms provide free SSL
5. **Custom domain** - You can add your own domain to both
